Data practices

Privacy policy

Effective date: 21 November 2026

This policy covers the Everyday Asia Publisher desktop utility and this informational website. The operator is Everyday Asia Explained. Contact: everydayasiaexplained@gmail.com.

Who uses the utility

The utility is operated by the owner of the Everyday Asia Explained YouTube channel for that channel's publishing workflow. This website does not provide a public sign-in or accept other creators' videos or Google credentials.

Data accessed and provided

With the owner's consent, the desktop utility receives Google OAuth access and refresh tokens and reads the authorized YouTube channel's identity. It sends the owner's video file, title, description, translated metadata, subtitle files, audience designation and approved publication time to YouTube. It reads video IDs, privacy and publication settings, processing results, and caption track IDs, languages and processing status to verify the operation.

Purpose and permission

These data are used to upload completed episodes, attach selectable captions, schedule releases, check the results, and resume interrupted work while avoiding duplicate uploads. The requested OAuth scope is https://www.googleapis.com/auth/youtube.force-ssl. The current utility does not read Gmail, contacts, payment information, or browsing history, and does not implement comment management, playlist management or video deletion.

Storage and security

OAuth client configuration, tokens and resumable upload state are encrypted with Windows Data Protection API for the current Windows user and stored outside the production workspace. Local files also include source media, subtitles, approved metadata, job manifests, upload receipts and operational logs. Logs and receipts are designed to exclude OAuth tokens and signed upload session URLs. The computer's owner controls access to the machine and its backups.

Sharing and public content

The utility transmits publishing data and authorization requests to Google/YouTube to perform the approved operation. YouTube stores uploaded content and makes it available according to the selected privacy settings and publication schedule. Public videos, descriptions and subtitle tracks become available to viewers when published. The desktop utility does not transmit OAuth credentials to this informational website, GitHub Pages or Zernio.

Google user data obtained by the utility are not sold, shared with advertising networks, or used to train general-purpose AI or machine-learning models. Any operator-authorized assistance must be limited to the disclosed publishing workflow.

Retention, removal and revocation

Local credentials, job state, logs and encrypted backup copies remain until the operator removes them. Media and receipts remain as production records until removed by the operator. YouTube content remains subject to the owner's YouTube settings and deletion controls. To stop access, revoke the application's permission in Google Account third-party connections, disable the local upload task, and remove stored credentials and any credential backup copies. Revoking access does not delete videos already uploaded to YouTube.

Website hosting

This static website is hosted on GitHub Pages. It has no application sign-in, forms, advertising scripts or analytics added by the operator. GitHub may process request data, including IP addresses and security logs, under the GitHub Privacy Statement. Opening a YouTube or Google link is subject to that service's privacy practices.

Google API Limited Use

Everyday Asia Publisher's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including its Limited Use requirements.

Changes and contact

Changes to data practices will be reflected on this page. New data uses requiring consent will require renewed authorization before use. For questions or removal requests, contact everydayasiaexplained@gmail.com.
